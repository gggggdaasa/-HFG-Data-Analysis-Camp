# HFG Data Analysis Camp

Projects and labs completed as part of the **HFG Data Analysis Camp** (Human for Good — انسان لأجل الخير).

## Structure

```
HFG-Data-Analysis-Camp/
├── SQL/                            # T-SQL labs — Window Functions on the HR database
│   ├── Lab1-HR-Compensation-Analysis/
│   ├── Lab2-Advanced-Window-Functions/
│   └── Lab3-Peer-And-Benchmark-Analysis/
├── PowerBI/                        # Power BI dashboard projects
│   └── Churn-Dashboard/
└── Final-Project/                  # Bank analytics: Excel + SQL + Power BI
```

## SQL Labs

| Lab | Focus | Link |
|---|---|---|
| **Lab 1** | Departmental compensation, employee performance ranking, and career progression tracking | [SQL/Lab1-HR-Compensation-Analysis](./SQL/Lab1-HR-Compensation-Analysis) |
| **Lab 2** | Percentile-based tiers, tenure quintiles, running totals, moving averages, and peer analysis | [SQL/Lab2-Advanced-Window-Functions](./SQL/Lab2-Advanced-Window-Functions) |
| **Lab 3** | Peer salary comparisons, hiring momentum windows, commission benchmarking, and premium job identification | [SQL/Lab3-Peer-And-Benchmark-Analysis](./SQL/Lab3-Peer-And-Benchmark-Analysis) |

**Tech:** T-SQL (Microsoft SQL Server) — `RANK()`, `DENSE_RANK()`, `ROW_NUMBER()`, `PERCENT_RANK()`, `NTILE()`, `LAG()`, `LEAD()`, `SUM() OVER`, `COUNT() OVER`, `AVG() OVER`
